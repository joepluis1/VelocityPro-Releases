# VelocityPro Releases

Official public release distribution repository and Over-The-Air (OTA) update feed for [VelocityPro](https://github.com/joepluis1/VelocityPro).

## Latest Download
- Download the latest standalone build: **[VelocityPro-1.0.1.zip](https://github.com/joepluis1/VelocityPro-Releases/releases/latest)**
- To install: Unzip and drag `VelocityPro.app` to your `/Applications` folder.

## Updates
Updates are automatically checked and distributed in-app using `appcast.json`.
